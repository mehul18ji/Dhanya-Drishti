# Taste

## Communication
- Never invent missing information (names, numbers, URLs, labels, citations); explicitly list missing values as gaps for the user to supply. Confidence: 0.7
- For long deliverables, split the output into two roughly equal parts: deliver the first half, stop, and wait for an explicit go-ahead before writing the second half instead of attempting one giant response. Confidence: 0.7

## Workflow
- When asked to "dig" into a problem, investigate and report findings only — do not modify files unless explicitly asked. Confidence: 0.75
- Investigative/analysis requests should be strictly read-only: no file creation or edits, no commits, pushes, deletes, moves, or restructuring. Confidence: 0.7
